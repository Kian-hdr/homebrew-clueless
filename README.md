```sh
brew install --cask Kian-hdr/clueless/clueless
```

If Homebrew requires trust for third-party casks, run `brew tap Kian-hdr/clueless` and `brew trust --cask Kian-hdr/clueless/clueless`, then retry the install.

Requires Apple Silicon and macOS 14.2 or later. This installs the same notarized app as the [Clueless GitHub release](https://github.com/Kian-hdr/clueless/releases/tag/v0.3.0).

See the [first-run guide](https://github.com/Kian-hdr/clueless/blob/main/docs/FIRST_RUN.md) for ElevenLabs and Codex setup.
